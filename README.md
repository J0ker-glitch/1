# Ускорение Android TV / Google TV

Тот самый трюк из рилсов: в скрытом меню разработчика уменьшаем (или выключаем)
анимации интерфейса — меню и переходы начинают открываться заметно быстрее.

> Работает на телевизорах и приставках с **Android TV / Google TV**
> (Xiaomi, TCL, Hisense, Sony, Philips, Haier, Mi Box, Chromecast with Google TV и т.п.).
> На Samsung (Tizen) и LG (webOS) такого меню нет — см. раздел ниже.

## Способ 1. Вручную с пульта (2 минуты)

1. **Настройки → Об устройстве** (иногда: *Настройки → Система → Об устройстве*).
2. Найдите пункт **«Сборка»** (Build / Android TV OS build) и нажмите на него **7 раз** подряд.
   Появится надпись «Вы стали разработчиком».
3. Вернитесь назад: **Настройки → Система → Для разработчиков**
   (или *Настройки → Настройки устройства → Для разработчиков*).
4. Пролистайте до блока **«Отрисовка»** и поменяйте три пункта:
   - **Анимация окон** → `0.5x` (или «Без анимации»)
   - **Анимация переходов** → `0.5x` (или «Без анимации»)
   - **Длительность анимации** → `0.5x` (или «Без анимации»)
5. Готово. Перезагрузка не нужна.

`0.5x` — быстро, но плавно. «Без анимации» — максимально быстро, но экраны будут «прыгать».

### Дополнительно (по желанию)
- **Лимит фоновых процессов** → «Не более 2–3 процессов» — помогает слабым ТВ
  с 1–2 ГБ памяти, но приложения будут чаще перезапускаться.
- **Настройки → Приложения**: удалите/отключите неиспользуемые приложения и
  очистите кэш тяжёлых (YouTube, кинотеатры).
- Отключите автозапуск и «рекомендации» на главном экране, если лаунчер тормозит.

## Способ 2. С компьютера через ADB (скрипт)

1. На ТВ: включите режим разработчика (шаги 1–3 выше) и **«Отладка по сети / USB»**.
2. Узнайте IP телевизора: *Настройки → Сеть → (ваша Wi‑Fi сеть)*.
3. Установите [Android Platform Tools](https://developer.android.com/tools/releases/platform-tools) на компьютер.
4. Запустите:

```bash
./scripts/tv-speedup.sh 192.168.1.50        # анимации 0.5x
./scripts/tv-speedup.sh 192.168.1.50 off    # выключить анимации
./scripts/tv-speedup.sh 192.168.1.50 reset  # вернуть как было (1x)
```

При первом подключении на экране ТВ появится запрос — разрешите отладку.

## Samsung / LG

У них нет меню разработчика с анимациями. Что реально помогает:
- **Samsung**: Настройки → Поддержка → Уход за устройством → «Оптимизация»;
  выключить *Instant On / Мгновенный запуск*-зависимые лишние приложения; Smart Hub → удалить ненужное.
- **LG**: Настройки → Общие → «Быстрый запуск+» включить; удалить лишние приложения;
  выключить «Рекомендации» на главном экране.
- Обоим: обновить прошивку и раз в неделю полностью выключать из розетки на 30 секунд.
